3. NAPREDNA PREDOBDELAVA SLIK

      Odstranjevanje pegastega šuma
      - Noise removal / reduction
      - Artefakti filtriranja, blur
      - Šum neodvisen od signala
      - Šum odvisen od signala

      Modeli šuma
      - Aditivni model: I(p) = X(p) + N(p)
      - Multiplikativni model: I(p) = X(p) N(p)
      - Predpostavke o šumu: μ_N = 0, varianca σ_N^2, bel / Gaussov šum

      Statistične mere
      - MSE
      - RMSE
      - PSNR
      - SNR (σ_I, σ_X, μ_I)
      - S/MSE
      - ENL (equivalent number of looks)

      Pegasti šum (speckle noise)
      - Multiplikativen šum
      - Interferenca razsipane energije
      - Koherentno slikanje (ultrazvok, SAR)
      - Zrnat izgled slike
      - Razsipovalci (scatterers), razdalje in faze
      - Destruktivna / konstruktivna interferenca
      - Odvisnost od hrapavosti površine
      - Lokalna svetlost in ehogeničnost

      Cilji filtrov pegastega šuma
      - Izboljšanje SNR
      - Ohranitev robov in linij

      Metode zmanjšanja pegastega šuma
      - Adaptivni mediani filter
        - Dve maski (H1, H2)
        - Prag T
      - Kuanov filter
        - MMSE
        - Unit-mean noise
        - Varianca signala σ_X^2
      - Leejev filter (MMSE)
      - Gama filter (MAP)
        - Gama porazdelitev
        - K porazdelitev
        - Parameter α
      - Frostov filter
        - Adaptivni Wienerjev filter
        - Exponential impulse response h
        - K, C_I, razdalja od središča okna
      - Oddyjev filter
        - Nizko sito
        - Adaptivno okno 3×3
        - Maska W_kl
        - Parameter α
      - Filter AFS (adaptive filter on surfaces)
        - Local emerging surface (l.e.s.)
        - Ploščina grafne ploskve
        - 5×5 maske, izbor minimalne l.e.s.
      - Wavelet-based denoising
      - Nevronske mreže za odstranjevanje šuma
        - MLP s K×L vhodi, 1 izhodom

      Barvna vztrajnost (colour constancy)
      - Barvna kalibracija
      - Perceptualna barvna vztrajnost pri ljudeh in živalih
      - Uniformna vs. neuniformna osvetlitev
      - Več virov svetlobe, sence
      - Počasi spreminjajoča se osvetlitev vs. hiter geometrijski/odbojni del

      Model formiranja barvnih vrednosti
      - Spektralni odziv S_v(λ)
      - Osvetlitev L(λ, p)
      - Odbojnost R(λ, p)
      - Geometrijski faktor G(p)
      - C_v(p) = ∫ S_v(λ) E(λ,p) dλ
      - Poenostavljen model Lambert, λ_v
      - C_v(p) = G(p) R_v(p) L_v(p)

      Algoritmi za barvno vztrajnost (uniformna osvetlitev)
      - White Patch Retinex (WPR)
        - Bela površina, maksimalna vrednost
        - L = max(C(p))
        - O(p) = C(p)/L
      - Gray World Assumption (GWA)
        - Povprečna barva v sliki
        - O(p) = C(p) / (ȳ_C^φ)
        - Faktor povečave φ

      Algoritmi za barvno vztrajnost (neuniformna osvetlitev)
      - CCN (comprehensive colour normalization)
        - Barvno normiranje
        - O′(p) = C(p)/(C_R + C_G + C_B)
        - GWA skaliranje
        - Iterativna shema, konvergenca
      - LSAC (local space average colour)
        - Počasi spreminjajoča osvetlitev
        - Lokalno povprečje ¯C(p) = C*K
        - 2D nizek filter (Gauss, eksponent)
        - Parametra a, ρ (dimenzija slike)
      - RSR (random spray retinex)
        - Bele površine, spreji pikslov
        - Radij r, število sprejev P, velikost K
        - O(p) = 1/P Σ C(p)/max_k C(p_p,k)

      Barvni kalibratorji
      - Colour checker
      - GretagMacbeth / X-Rite
        - Naravne barve
        - RGB + CMY barve
        - Sivinska lestvica
      - QP201
      - Uporaba pri ocenjevanju algoritmov barvne vztrajnosti
      - Merjenje uspešnosti (MSE, RMSE, itd.)

4. NAPREDNA SEGMENTACIJA

      Modeli aktivnih kontur – kače (snakes)
      - Deformable spline
      - Minimization of energy
      - Interne sile (gladkost, kontinuirnost)
      - Slikovne sile (robovi, linije, zaključi)
      - Zunanje sile (omejitve, user input)
      - Parametrična predstavitev v(s) = [x(s), y(s)]

      Energijski funkcional kače
      - Esnake = ∫ (E_int + E_image + E_con) ds
      - Interna energija
        - E_int = 1/2 (α|v_s|^2 + β|v_ss|^2)
        - Membranski člen (prvi odvod)
        - Thin-plate člen (drugi odvod)
        - Parametra α(s), β(s)
      - Slikovna energija
        - E_image = w_line E_line + w_edge E_edge + w_term E_term
        - E_line = I(x,y)
        - E_edge = -|∇I|^2
        - E_term (curvature v nivojskih setih)
        - Gaussovo glajenje C(x,y) = G_σ * I

      Numerična rešitev kač
      - Diskretizacija krivulje (n vozlišč)
      - Diskretizacija energije
      - Matrika A (pentadiagonalna, n×n)
      - Parametri a, b, c v matriki A
      - Zunanje sile F_x, F_y
      - Eulerjev korak
      - Iterativni posodobitveni zakon:
        - x_t = (A + γI)^(-1) (γx_(t-1) - F_x)
        - y_t = (A + γI)^(-1) (γy_(t-1) - F_y)
      - Konvergenčni pogoji
      - Ponovna enakomerna razporeditev vozlišč

      Problemi in parametri kač
      - Inicializacija začetne krivulje
      - Vpliv parametrov α, β, w_line, w_edge, w_term
      - Primeri dobrih in slabih segmentacij
      - Število iteracij, stopnja koraka γ

      Razširjene kače in aplikacije
      - GVF (Gradient Vector Flow snakes)
      - Balloon snakes
      - Diffusion snakes
      - Sledenje objektom v video sekvencah
      - Stereo ujemanje (Estereo)

      Analiza neodvisnih komponent (ICA) – segmentacija
      - Osnovni pojem ICA
      - Uporaba za ločevanje komponent v slikah
      - Uporaba pri segmentaciji
